# Recall Demo Script

## Objective

Demonstrate how persistent memory can improve continuity
in an AI-powered customer support interaction.

## Demo Scenario

A customer previously contacted support about a connectivity
problem and now returns with a follow-up question.

## Walkthrough

### 1. Introduce the problem

Explain that customers may have to repeat details when
support conversations lack continuity.

### 2. Start the first interaction

Sign in using a designated demo account and describe a
realistic, synthetic support issue.

### 3. Show memory

Open the memory interface and demonstrate the information
retained by Hindsight, where available.

### 4. Continue the interaction

Return to the chat and ask a follow-up question that depends
on the earlier context.

### 5. Explain the result

Show the recalled context and explain how it informed the
agent's response.

## Key Message

Recall demonstrates how persistent memory can help an AI
support agent maintain context across interactions.

## Demo Safety

Use synthetic customer details and test accounts only.
Do not expose API keys, private user information, or
confidential conversation logs.
